# AI chat history

The only AI tool used for this task was **Claude Code** (the VS Code extension). No web chats (ChatGPT, Claude or Gemini on the web) and no other editor tools were used, so there is no `links.txt`.

`claude_code/` holds the Claude Code `.jsonl` session files for this project, copied unedited from `~/.claude/projects/` by `tools/export_chats.py`. The only change allowed by the brief is replacing passwords and API tokens with `[REMOVED]`, and none were found in the transcript. The session was continued after context compaction, so the full history is in the same file.
